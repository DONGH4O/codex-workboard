## 目标与完成定义

目标是在不修改 Codex 桌面应用、不读取或改写 Codex 私有存储格式的前提下，将上游 macOS Electron 应用适配为可在本机 Windows x64 上运行的独立应用，并通过 [OpenAI 官方 Codex App Server](https://developers.openai.com/codex/app-server) 与 Codex 交互。

只有同时满足下列条件，才能将项目标记为“Windows 本机适配完成”：

- Windows 源码构建、单元测试和静态检查通过。
- Windows 窗口具有可用的最小化、最大化、关闭、拖动和缩放行为。
- 应用能在同一进程环境中识别经过验证的 Codex CLI，明确报告版本、登录状态和协议状态。
- App Server 初始化、模型列表、当前及归档对话同步、会话读取、会话创建、续聊、引导、中断和审批流程均有真实证据。
- Workboard 数据位于独立目录；重启、中断恢复、备份和卸载边界得到验证。
- Windows 便携版通过自动验证和人工界面验收。
- 是否安装 NSIS 版本、是否发布 GitHub Release，由用户分别确认；自动验证通过不能替代人工验收或发布授权。
